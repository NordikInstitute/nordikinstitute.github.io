01 / THE BIG QUESTION

What is this research about?

Libraries are more than books. NORDIK Institute and Ontario Library Service developed a common Social Return on Investment framework to help public libraries describe and measure their contributions to community life.

“How can Ontario's public libraries communicate the breadth of their social and economic value?”
02 / THE APPROACH

How the work comes together.

  • Develop a shared Social Return on Investment framework based on engagement across Ontario.
  • Measure value through seven domains: education, culture, inclusion and wellbeing, entertainment and leisure, economic development, civic engagement, and space.
  • Gather feedback from toolkit users and revise the resource.
03 / WHAT WE'RE LEARNING

Findings & progress.

  • The province-wide toolkit launched in December 2023, building on the 2016 Valuing Northern Libraries Toolkit.
  • The poster reports that many Ontario libraries now use the toolkit to generate Library Value Reports.
  • The current project phase is focused on revisions based on user feedback.
